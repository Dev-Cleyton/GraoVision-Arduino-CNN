# Aplicacao Python V10.1

Leia `../README_V10_1.md` antes de usar. Chave Roboflow deve ficar SOMENTE em `.env` local (modelo `.env.example`).

Executar testes offline: `python -m unittest discover -s tests -v`

Executar integracao: `python main.py`, com cargas de potencia desconectadas e movimentos simulados por padrao.

Relatorios: `relatorios/<ID>_relatorio.json`, `relatorios/<ID>_pesagens.csv`. Nao informamos 'umidade do grao' com dados do NTC.
